## AICTE — EduSkills Virtual Internship (8 Weeks)

### Domain — Google AI-ML

#### 📌 Overview

This repository contains the assignments, hands-on tasks, and project documentation completed during my **8-Week AICTE — EduSkills Virtual Internship** in **Google AI-ML**.

The program focused on building industry-relevant skills through structured weekly modules, practical implementations, and a capstone project assessment.

#### 📚 Week-wise Curriculum

The week-wise structure of the internship is as follows:

| Week | Module | Description |
|:---:|---|---|
| 1 | Program neural networks with TensorFlow | Understand the fundamentals of machine learning and create convolutional neural networks for advanced image recognition and classification. |
| 2 | Get started with object detection | Learn the basics of object detection and integrate pretrained object detectors into mobile applications. |
| 3 | Go further with object detection | Train custom object-detection models using TensorFlow Lite and Model Maker. |
| 4 | Get started with product image search | Build a product image search feature using on-device object detection. |
| 5 | Detect objects for visual search | Detect objects in static images and live camera feeds for visual product search. |
| 6 | Go further with product image search | Build backend integration for product image search mobile applications. |
| 7 | Go further with image classification | Build custom image-classification models and improve classification skills. |
| 8 | Integrate a custom image classifier | Create and integrate a custom image classifier model into an application. |
